# 🚀 Featured Projects

## 1. SLA-Aware Cost-Optimized Cloud Auto-Scaling Using Deep Reinforcement Learning

### 🔗 Repository

https://github.com/prudhvimareedu/SLA-Aware-Cost-Optimized-Cloud-Auto-Scaling

### 📌 Description

An intelligent cloud auto-scaling system developed using **Deep Reinforcement Learning (DRL)** to dynamically adjust cloud resources based on workload and system performance.

The system aims to balance:

- Application performance
- Service Level Agreement (SLA) requirements
- Resource utilization
- Cloud infrastructure cost

### ⚙️ Key Features

- Intelligent cloud resource auto-scaling
- Deep Reinforcement Learning based decision making
- CPU utilization monitoring
- Memory utilization monitoring
- Response-time monitoring
- Request-rate monitoring
- SLA violation detection
- Workload forecasting
- Cost-aware resource management
- Real-time monitoring dashboard
- Explainable AI using SHAP

### 🧠 Technologies Used

- Python
- Deep Reinforcement Learning
- FastAPI
- React.js
- Machine Learning
- LSTM
- SHAP
- REST APIs
- Cloud Computing

### 🏗️ System Components

The project contains multiple intelligent components including:

- Transformer State Encoder
- Resource Agent
- Actor-Critic Architecture
- Lagrangian Safe Reinforcement Learning
- Workload Forecaster
- LSTM-based forecasting
- Prioritized Experience Replay
- SLA-DRL Controller
- PPO Fine-Tuning
- SHAP-based Explainability

### 🎯 Objective

The primary objective is to automatically scale cloud resources while maintaining application performance and reducing unnecessary infrastructure costs.
